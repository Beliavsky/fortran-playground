Run compiles and executes your program using GNU Fortran with default options. Compilation errors appear below Program output.

    
Compile checks and builds without running. Compile and Run builds and executes; Run Again executes the retained build without recompiling. With ofort, Check syntax validates without execution and Run interprets source afresh. Existing python_mod helpers are available automatically with compilers, not ofort. No Python code is submitted or translated.

    
Compiler/interpreter availability is reported by the service. Failures never silently switch tools. ofort is experimental: standalone source only, no compiled python_mod helpers. Its syntax check does not execute code; uninitialized-variable checks occur during execution.

    
100 KB source limit · 200 KB per output stream · no interactive input · every run starts afresh.

    
Hosted runs use the shared Python-to-Fortran execution service and its workload limits. Programs run in isolated environments without network access. Running a local preview still sends execution jobs to that hosted service.
