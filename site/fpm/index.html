Public GitHub repositories with a root fpm.toml. GitHub git dependencies and paths within a repository are supported; registry dependencies and metapackages are not yet supported.

Each submission builds from scratch. Build limit: 180 seconds; run/test limit: 30 seconds total. Execution has no network access. Missing libraries, unsupported features, and larger packages may fail.

FPM has a separate job queue and usage allowance: 30 jobs per address per ten minutes and 100 public jobs per day. See instructions and limitations.
