Public GitHub repositories with a root fpm.toml, or a package directory in the translated R collection. Translated R packages build from scratch and are available to attempt; inclusion does not mean they have been verified in this playground. GitHub git dependencies and paths within a repository are supported; registry dependencies and metapackages are not yet supported.

Available packages reuse verified GNU 16 libraries for your main program at the listed revision. Other submissions build from scratch. Build limit: 180 seconds; run/test limit: 30 seconds total. Execution has no network access. Missing libraries, unsupported features, and larger packages may fail.

FPM has a separate job queue and usage allowance: 30 jobs per address per ten minutes and 100 public jobs per day. See instructions and limitations.
