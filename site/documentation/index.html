Generation log and warnings


Experimental: no preprocessing, source INCLUDE directives, external dependency documentation or repository-specific FORD settings. Files under vendor and third-party directories are excluded. Some packages need custom settings and will not work with this pilot. Nothing is compiled or executed.


Generation is limited to 120 seconds, 1,500 source files and 32 MiB of source. Generated documentation is cached by source snapshot, revision, settings and FORD version.


Local alternative: install ford==7.0.13, then run python xford.py PATH --serve in a checkout of this playground. PATH can also be a public GitHub repository URL.
