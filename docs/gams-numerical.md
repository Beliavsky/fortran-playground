# Numerical package GAMS review

All 120 selected packages with a top-level A–M or P assignment have been reviewed at their pinned revisions: 119 have procedure mappings and 1 supplies supporting declarations rather than numerical procedures. There are 149 procedure records. This scope includes arithmetic, statistics, geometry, and supporting data utilities, alongside numerical solvers.

This is an initial procedure-level coverage pass, not an exhaustive inventory of every routine or every overload. Specific assignments require evidence for the named procedure and configuration. Other package capabilities remain discovery classifications. Source review does not imply a new compilation test, accuracy certification, or benchmark.

The [Netlib GAMS taxonomy](https://netlib.org/misc/gams.html) supplies the additional detailed labels and hierarchy; the existing top-level and immediate classifications come from [NIST GAMS](https://gams.nist.gov/cgi-bin/serve.cgi). Labels such as “General” must be read with their ancestors. C1/C10 and L1/L10 are siblings, and explicit parent links preserve that distinction.

## Evidence and next steps

- Source archives were downloaded at catalog revisions and checked against the catalog archive SHA-256 hashes. Procedure and example records include paths, source SHA-256 hashes, and source line anchors.
- Author examples and tests are usage candidates, not a promise that they run unchanged within sandbox limits. The catalog main may exercise only one of the package’s mapped APIs. Only the separately recorded [G1 drivers](gams-g1.md) have the new driver-verification designation.
- Generic APIs retain broader classes where real/complex arithmetic, matrix structure, derivatives, or constraints depend on configuration. Detailed optimization mappings state the derivative mode; derivative-free modes need separate records.
- Next, refine the discovery-only queue, split overloaded APIs where useful, and adapt suitable author examples into independently checked drivers. Use common mathematical problems when comparing packages; one successful example is not a performance ranking.

## Maintenance

Edit procedure mappings in [gams.json](../fpm_catalog/gams.json) and update the coverage ledger [gams-numerical-review.json](../fpm_catalog/gams-numerical-review.json). Revision and archive pins must match the selected catalog. The ledger explicitly records supporting utilities and prevents a newly added numerical package from silently escaping review.

Run `python xpackage_gams.py` to validate and regenerate the review pages, `python xfpm_examples.py` to publish search metadata, and `python xcatalog_export.py` to export the reusable classifications. These commands do not compile packages or redeploy Modal.
